# Mega Drive Emulator (JavaFX demo)


This is a minimal skeleton project that demonstrates a Mega Drive emulator structure using **JavaFX** for rendering. It includes placeholders for CPU, Memory, Cartridge and VDP. LWJGL is listed as an optional dependency stub if you want to later integrate a native OpenGL window or advanced input/audio handling.


## Requirements
- Java 17+
- Maven


## Build & Run (using the javafx-maven-plugin)


```bash
mvn clean javafx:run
```


If you prefer to run the generated jar directly, export with `mvn package` and run with the proper JavaFX module path for your system.
